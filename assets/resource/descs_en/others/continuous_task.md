## **Routine Tasks**

Routine tasks are tasks that can automatically continue to the next task after the current one finishes. They usually have the following characteristics:

1. **Same entry and exit context**: Both the start and end screens are the main screen.
2. **Continuous flow**: Multiple tasks can be chained into one execution flow without manual intervention.

When configuring routine tasks, pay attention to dependencies and ordering so the task chain can execute correctly.
