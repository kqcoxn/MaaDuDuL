## **Close Game**

**[Routine Task] [Daily Task]**

#### **Feature**

Close the game client automatically. This does not close the emulator itself. If you also want to close the emulator, configure that in the MDDL settings panel.

#### **Start / End Screen**

- **Start**: Any screen
- **End**: The screen shown after the game has been closed

#### **Suggestion**

It is recommended to run this task at the very end of your workflow.
