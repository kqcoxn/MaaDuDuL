## 目前的打包方式

每次正式发布会生成一个签名的 `MaaDuDuL-vx.x.x-android-universal.apk`。它以 [MaaFwApp](https://github.com/Aliothmoon/MaaFwApp) 为界面，已内置 MDDL 任务资源、MaaFramework 和 Python Agent。`universal` 表示同一个 APK 包含 `arm64-v8a` 与 `x86_64` 两种架构，不需要分别下载。请从 [MDDL GitHub Releases](https://github.com/kqcoxn/MaaDuDuL/releases) 下载对应版本的 APK；旁边的 `build-info.json` 是发布校验记录，普通用户无需下载。

Android 端目前仍在试用阶段，暂未接入 Mirror 酱。桌面版 ZIP、桌面端安装依赖和模拟器连接步骤均不适用于这个 APK。

## 安装和授权

1. 确认设备运行 **Android 9 或更新版本**，并安装游戏的 B 服。当前 MDDL 资源仅适配 B 服。
2. 在手机上安装从 MDDL Release 下载的 APK。若系统提示允许浏览器或文件管理器安装此应用，请核对文件来源后按系统指引操作。
3. 准备 [Shizuku](https://shizuku.rikka.app/guide/setup/) 或 root 权限，二选一。在 MDDL 中选择对应方式并完成授权，等待服务连接成功。没有连接特权服务时可以查看界面，但无法执行任务。
4. 按应用提示授予所需的通知权限；计划定时运行时，也建议按系统设置允许后台运行、关闭对 MDDL 的电池限制。
5. 先检查任务配置，再选择少量任务试运行，确认截图、识别和点击都正常后再增加任务。

::: tip Shizuku 启动方式
Android 11 及以上可按 Shizuku 官方说明通过无线调试启动，无需一直连接电脑；重启手机后通常需要重新启动 Shizuku。Android 9/10 若无 root，启动 Shizuku 需要连接电脑。具体步骤以 [Shizuku 官方指南](https://shizuku.rikka.app/guide/setup/)为准。
:::

## 使用建议

- 先选择重复日常任务进行测试。新账号、未解锁的玩法或活动界面变化，可能使原有任务流程不适用。
- 更新时从本项目 Release 下载新版 APK 并安装。若系统提示无法覆盖安装，不要直接卸载旧版；先导出或备份配置，并反馈所用版本与安装错误。
- 出现失败时，在应用内导出运行日志，附上 Android 版本、设备型号、所用权限方式及任务名称，到 [GitHub Issues](https://github.com/kqcoxn/MaaDuDuL/issues) 反馈。

Android 端的界面和权限操作由 MaaFwApp 提供，可参阅其[项目说明](https://github.com/Aliothmoon/MaaFwApp/tree/v0.1.0)。
