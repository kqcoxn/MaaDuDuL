## 下载前须知

**对于下列情况，MDDL 不提供支持**：

- win7 及更早版本的 windows 系统
- 各类定制系统（如 XOS 等非官方系统）、精简系统（包括官方与非官方）与微 PE 系统（辅助安装环境）
- HarmonyOS、IOS 等非安卓派生系统
- 国际服等其他非大陆服务区

**对于以下情况，MDDL 可能经常出现卡顿、失败等情况**：

- 网络环境波动较大或电脑硬件配置较差（经常出现游戏内微卡顿）
- 当前同时运行大量模拟器或其他高算力需求的游戏、生产力工具等
- 游戏处于开荒期，Box/事件解锁不满足 MDDL 逻辑需求（MDDL 只是帮忙完成重复日常，账号新内容无法跳过）
- 其他神秘设备原因

> 如果您不确定是否处于上述某一种情况，可以在群内请教群友。

## 选择设备

请按运行 MDDL 的设备阅读对应章节，每个章节都列出了应下载的文件和安装步骤：

- [Windows 安装](/user/init/windows)：Windows 10/11，使用 ZIP 桌面包。
- [macOS 安装](/user/init/macos)：Apple Silicon 或 Intel Mac，使用 ZIP 桌面包。
- [Linux 安装](/user/init/linux)：x86_64 或 ARM64，使用 ZIP 桌面包。
- [Android 安装与使用](/user/init/android)：Android 9 及以上，直接安装 APK，目前处于试用阶段。

如果希望**由电脑控制 Android 实体设备**，请参阅 [MaaFramework 的 Android 设备说明](https://maa.plus/docs/zh-cn/manual/device/android.html)。这种方式与在手机上直接安装 APK 不同。

## 下载 MDDL 安装包

您可以通过多种方式下载 MDDL，**选择一种即可**。

::: tip
**您无需下载列出的所有文件，而是根据上一步确定好的文件名下载对应文件即可！**
:::

### QQ 群文件

您可以在 [MDDL 交流群（926874985）](https://qm.qq.com/q/EGUgYodNqo)内的**群文件夹**找到 `Win-X86` 与 `Mac-Arm64` 系统的安装包

![](/images/user/QQ群文件.png)

### Github Release

您可以在 Github Release 中下载 MDDL 的任意版本。

首先，打开 [MDDL Github Release 页面](https://github.com/kqcoxn/MaaDuDuL/releases)，最顶部的即为最新版。

::: tip 可能的问题：Github 页面打不开/下载缓慢

国内对于 Github 的防火墙时有时无，且速度非常不稳定。如果条件允许，请使用网络代理或加速器访问。

如果您无法通过其他途径进入 Github 页面，请使用其他方式下载 MDDL。
:::

在 Assets 中找到适合自己系统的版本，点击文件名即可下载。（若下载缓慢请参考上述问题）

![](/images/user/GithubRelease.png)

### Mirror 酱

在 [Mirror 酱](https://mirrorchyan.com/zh/projects?rid=MaaDuDuL&os=windows&arch=x64&channel=stable&source=MDDL-docsite) 官方的帮助下， MDDL 同样也接入了 Mirror 酱的国内高速下载与更新服务。

目前 Mirror 酱只提供桌面包；Android APK 请从 GitHub Release 获取，详见[安卓端安装与使用](/user/init/android)。

**您可以通过 [此链接](https://mirrorchyan.com/zh/projects?rid=MaaDuDuL&os=windows&arch=x64&channel=stable&source=mddl-docsite) 获取任意版本的 MDDL**。

简单来说，Mirror 酱（简称 mirrorc）是一个由开源社区维护的有偿分发平台，可以理解为一个中转站，从海外源获取一份最新版存至国内站点，当您需要时直接从国内站点下载。（实际为全球加速）

由于海内外下载、站点维护等需要，mirrorc 会产生大量开销，因此 mirrorc 的服务是有偿的，但这**并不代表 MDDL 是收费的，您完全可以通过其他方式更新并无限制使用，仅在您需要 mirrorc 时才需要自行向 mirrorc 方付费，MDDL 社区并不承担此过程中的一切责任，当出现问题时您可以联系 mirrorc 客服解决。**

下载后请返回对应平台章节，继续完成安装和启动。
