## 选择安装包

从[下载与安装](/user/init/install)介绍的渠道获取对应 ZIP：

| Mac 类型 | 文件名 |
| --- | --- |
| Apple Silicon（M 系列芯片） | `MaaDuDuL-macos-aarch64-vx.x.x.zip` |
| Intel | `MaaDuDuL-macos-x86_64-vx.x.x.zip` |

可在苹果菜单的“关于本机”中查看芯片或处理器类型。下载的是 **ZIP**，请勿照搬旧版 `tar -xzf` 命令。

## 解压

推荐解压到用户目录，无需管理员权限。打开“终端”，把下面的文件名换成实际下载的版本和架构：

```bash
mkdir -p "$HOME/MaaDuDuL"
unzip -q "$HOME/Downloads/MaaDuDuL-macos-aarch64-vx.x.x.zip" -d "$HOME/MaaDuDuL"
```

例如，Intel Mac 应把文件名中的 `aarch64` 换成 `x86_64`。如果压缩包不在“下载”目录，也请换成实际路径。保持解压出的文件夹完整，程序运行需要同目录中的资源和 Python 环境。

## 准备游戏环境

macOS 可以通过**支持 ADB 的 Android 模拟器**或 **PlayCover** 运行游戏。先启动游戏，再启动 MDDL：

- 使用模拟器时，确认模拟器已启动并开放 ADB 连接；建议设置为 **16:9 横屏**、至少 **30 FPS**。在 MDDL 中选择“模拟器”控制器。
- 使用 PlayCover 时，在 MDDL 中选择“PlayCover”控制器；模拟器与 PlayCover 的准备方式可参考 [MAA 的 Mac 模拟器说明](https://docs.maa.plus/zh-cn/manual/device/macos.html)，连接时请以 MDDL 界面中的控制器为准。

## 启动 MDDL

在终端进入解压目录，运行 `MaaDuDuL` 启动图形界面：

```bash
cd "$HOME/MaaDuDuL"
./MaaDuDuL
```

这会启动 MDDL 的图形界面；后续也可用同样的命令启动。如果提示 `permission denied`，先在解压目录中运行 `chmod +x MaaDuDuL`，再执行 `./MaaDuDuL`。

## 遇到 macOS 安全提示

如果系统提示“无法验证开发者”或无法检查是否包含恶意软件，先确认 ZIP 来自本项目的 [GitHub Release](https://github.com/kqcoxn/MaaDuDuL/releases)。尝试运行一次后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)到“系统设置 → 隐私与安全性”选择“仍要打开”。

如果系统设置中没有该选项，且确认安装包来源可信，可仅对**当前解压的目录**移除下载隔离属性，然后重新启动：

```bash
xattr -dr com.apple.quarantine "$HOME/MaaDuDuL"
cd "$HOME/MaaDuDuL"
./MaaDuDuL
```

以上命令会影响该目录下所有文件，请勿对其他下载目录或整个系统运行。操作思路参考 [M9A 的 macOS 安装说明](https://1999.fan/zh_cn/manual/newbie.html#macos)；这里的文件名、路径和 ZIP 解压方式已按 MDDL 当前发布包调整。

程序打开后，继续阅读[桌面端初始化](/user/init/run)，连接已启动的模拟器或 PlayCover，再尝试单个任务。
