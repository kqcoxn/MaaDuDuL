## 选择安装包

从[下载与安装](/user/init/install)介绍的渠道获取对应 ZIP：

| 处理器架构 | 文件名 |
| --- | --- |
| x86_64 | `MaaDuDuL-linux-x86_64-vx.x.x.zip` |
| ARM64 | `MaaDuDuL-linux-aarch64-vx.x.x.zip` |

## 解压并启动

以 x86_64 版本为例，打开终端，把文件名换成实际下载的版本和架构：

```bash
mkdir -p "$HOME/MaaDuDuL"
unzip -q "$HOME/Downloads/MaaDuDuL-linux-x86_64-vx.x.x.zip" -d "$HOME/MaaDuDuL"
cd "$HOME/MaaDuDuL"
./MaaDuDuL
```

如果系统没有 `unzip`，请先通过发行版的包管理器安装。保留解压目录中的资源和 Python 环境；不要直接从压缩包内启动程序。程序打开后继续阅读[桌面端初始化](/user/init/run)。
