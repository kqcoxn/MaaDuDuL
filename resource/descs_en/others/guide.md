## **Operation Guide**

### Client

The home page is the task configuration panel:

- **Current Profile**: Quickly switch between different profiles. Profiles can be created from the settings panel.
- **Resource Type**: The current built-in resource pack targets the Bilibili CN server.
- **Task Settings**: Different tasks expose different options, which you can adjust based on your own needs.
- **Task Description**: The description panel contains task notes, parameter explanations, and other reminders.
- **Controller**: Your emulator or device information. If you run multiple emulators, configure the matching controller manually. PlayCover is also supported.
- **Task List**: After you click start, MDDL will **run every checked task in order**.
  - **Basic actions**: Left click the checkbox to toggle a task. Right click it to run the task once and then automatically uncheck it.
  - **Batch actions**: Use the quick-action buttons in the top-right corner of the task list to select all, clear all, or add tasks. Tasks can be added repeatedly and can appear multiple times in the list.
  - **Execution order**: Drag tasks in the list to change their run order.
  - **Parameter adjustment**: Left click the gear icon on the right side of a task to adjust its parameters in the settings panel.
  - **Remove task**: Right click the gear icon of a task already in the list, then remove it.
  - **Run individually**: Right click the gear icon of a listed task, then choose to run only that task.
  - **Run from here**: Right click the gear icon of a listed task, then run the current task and all tasks after it.
- **Live View**: Shows the current game screen. Frame rate can be adjusted in settings, but values that are too high may hurt performance.
- **Logs**: Shows MDDL log output. If something fails, check the logs first.

> Each panel can be hidden, resized, and dragged. Adjust the layout however you prefer.

Click the gear icon in the lower-left corner to open the GUI settings panel. There you can configure MDDL itself, including switching profiles, **scheduled task execution**, connection settings, pre/post launch actions such as **starting or closing emulators**, theme settings, external notifications, **update source settings** (MirrorChyan), software updates, and more.
