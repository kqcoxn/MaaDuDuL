## **Trick Dice**

**[Independent Task]**

#### **Feature**

Play Trick Dice automatically. Select a mode in the task settings:

- **Daily tasks (default)**: Complete the remaining plays toward three daily matches, then claim play rewards and available daily achievement rewards. The child option “Check only once per day” is enabled by default.
- **Repeat matches**: Play the configured match count (default: 10), stopping early if free entries run out.

#### **Start / End Screen**

- **Start**: Main screen or Trick Dice lobby
- **End**: Daily tasks return to the main screen. Repeat matches stop in the dice lobby; stopping manually leaves the current screen open.

#### **Notes**

- Simplified Chinese game interface only.
- Uses existing free entries; does not purchase entries.

See the [documentation](https://mddl.codax.site/docs/algorithms/trick-dice) for the algorithm and score distribution.
